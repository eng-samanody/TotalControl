# Third-Party Notices

## jSSC 2.8

The project vendors jSSC 2.8 under `third_party/maven/` for serial-port access. The original bundled release included `COPYING` and `COPYING.LESSER`, indicating GPL/LGPL licensing terms for jSSC. Copies are retained at `docs/licenses/jssc-COPYING` and `docs/licenses/jssc-COPYING.LESSER`. Keep those obligations in mind when distributing binaries.

Recommended maintenance:

- Record the upstream source URL and checksum for any vendored jar update.
- Re-run hardware smoke tests after changing the serial library.
- Include jSSC license text in binary distributions.

## UI Image Assets

Image assets live under `src/motorcontrol/img/`. Their original provenance is not documented in the historical project files. Before public redistribution, verify ownership or replace them with assets whose license is known.
