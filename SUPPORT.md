# Support

This repository is maintained by the repository owner.

## Supported Version

The supported version is the current `master` branch unless a GitHub Release states otherwise.

## Getting Help

Open a GitHub issue with:

- TotalControl version or commit SHA
- operating system and architecture
- JDK version
- serial device and firmware version
- serial settings used
- steps to reproduce
- expected behavior and actual behavior
- logs or screenshots if relevant

For hardware-dependent bugs, include the completed test context from `docs/hardware-test-plan.md`.

## Not Supported

- Undocumented firmware command protocols
- Unknown or unlicensed UI asset redistribution
- Platforms not supported by the bundled jSSC native libraries
- Prototype remote/network or Bluetooth features hidden from the production UI
